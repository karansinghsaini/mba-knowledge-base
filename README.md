## How Each Note Is Structured
Every topic file follows a consistent format for quick review:
1. **Core Concept:** A plain-English summary of the theory or framework.
2. **Key Formulas / Models:** Essential equations, matrices, or decision trees.
3. **Tech & Industry Application:** How this concept applies to software products, engineering teams, or global tech firms.
4. **Key Takeaways:** Actionable bullet points for decision-making.
